# XGuardiam Ride Mobile

App mobile inicial do XGuardiam Ride em React Native, Expo, TypeScript e Expo Router.

## Configuracao

```bash
npm install
```

Crie um `.env` a partir do exemplo:

```txt
EXPO_PUBLIC_API_BASE_URL=http://localhost:3001/api
```

Em celular fisico, troque `localhost` pelo IP da maquina na rede local, por exemplo:

```txt
EXPO_PUBLIC_API_BASE_URL=http://192.168.0.10:3001/api
```

## Rodar

```bash
npm run start
```

O backend `xguardiam-ride-api` deve estar rodando em outro terminal.
